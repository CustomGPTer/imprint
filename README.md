# Imprint

Imprint is a free Android app for watermarking. Make a mark once from words, a logo, shapes, a signature or a QR code, and put it on a photo, a batch of photos, a PDF or a video. No adverts, no account.

Website: https://customgpter.github.io/imprint/

Download: https://github.com/CustomGPTer/imprint/releases/latest/download/Imprint.apk
